Translation

Runs Chrome's built-in Gemini Nano model locally – no API key, no server. It follows the same natural-dialogue instructions as Ollama and reads up to eight earlier lines of this video. Needs Chrome 138+ with a capable GPU (or 16 GB RAM) and ~22 GB free disk; click Prepare model once to download it (~2 GB). Best output quality in English, Spanish and Japanese.

When a video is found (usually before it starts) or paused, reads the tab title and page description once per page and looks up a short synopsis on Wikipedia (sends the title to wikipedia.org). The model uses it for names, relationships and terminology. Scripts or transcripts are never fetched.

Checks every 1 s and runs a tiny Gemini Nano prompt after at least 0.25 s idle to reduce GPU idle gaps between subtitles. Uses extra GPU power and may increase heat; cannot guarantee steady fan speed. Real translations interrupt it. Stops when the video is paused or the tab is hidden.

Ollama is instructed to translate intended meaning naturally, using supplied dialogue for ambiguous words, tone, and story continuity. It does not see the video; enable subtitle context above for preceding dialogue and story context for the show's background.

Start Ollama with OLLAMA_ORIGINS=chrome-extension://* so it accepts requests from the extension.

Downloads Xenova/opus-mt-zh-en (~100 MB) from Hugging Face once, then runs offline.
